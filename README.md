# kimlalman28.github.io

Personal portfolio website for Kimberly Lalmansingh, hosted on GitHub Pages.

## About

This repository contains a single-page portfolio website showcasing professional experience, technical skills, and career journey as a software engineer. The site is built with pure HTML/CSS and is accessible at [https://kimlalman28.github.io](https://kimlalman28.github.io).

## Structure

- **index.html** - Self-contained portfolio website with inline styles
- Minimalist design requiring no build process or dependencies
- Responsive, mobile-friendly layout with smooth scrolling navigation

## Content

The portfolio features:

- **Hero Section**: Introduction and professional tagline
- **About Me**: Timeline-based career history including:
  - Rhino (Tech Lead/Senior Software Engineer, 2018-2022)
  - SyncIoT Technologies (Full Stack Developer)
  - Queens Library (Software Engineering Intern)
  - NYC Tech Talent Pipeline (Resident)
  - Queens College (B.S. Computer Science, 2014-2018)
- **What I'm Doing**: Current activities (in progress)
- **Outside Work**: Personal interests (in progress)
- **Footer**: LinkedIn, GitHub, and email contact links

## Design

Clean, modern single-page application with:
- Pastel color scheme for visual appeal
- Sticky navigation for easy access
- Timeline visualization for professional experience
- Smooth scrolling between sections

## Technologies

- HTML5
- CSS3 (inline styles)
- No JavaScript frameworks or build tools required

## Deployment

Automatically deployed via GitHub Pages. Any changes pushed to the main branch are reflected at the live site.
